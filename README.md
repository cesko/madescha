Madescha
========

*Mach deine scheiß Ablage!*

Helps you organise important documents, letters, certificates, with out vendor login.

This is a **Minimum Viable Product!** and barely tested. Use with care.

## The Core Idea

1. Have a scanned document
2. Open it in Madescha
3. Madescha runs OCR and local AI to help you categorize the document
4. Export file - Madescha helps you stick to a naming convention

## Install and Dependencies

For now, only Linux install is supported.

Install using the install script:

```bash
./install.sh
```

Additionally, you will need Ollama installed to run the local AI stuff.


## Usage

Open **Madescha** and click "Open Document" to get started.

Alternatively, you can right-click a PDF document in your file explorer, select "Open with" and chosse **Madescha**.

Once opened, the document is processed/parsed automatically. Once completed, the basic document information (author, title, date and keywords) are displayed in the editable fields.

You are now free to adjust the document information, if needed. The *author short name* is used for the exported file name only. Choose something sensible.

Once satisfied, click export, and select a directory. You may not select a file. If you have accidentally selected a file, you might need to manually remove the filename in the field.

The exported file will contain the text layer generated by OCR and tags based on the document information. 


## Technology

- Developed in Python
